# 依据参考文章调整文风

本方法用于学习用户指定的参考文章或本人既往作品，将其表达特点应用于当前稿件。当前稿件决定科学内容，参考文章提供表达依据；措辞、节奏和组织方式的调整始终服从内容与证据保持规则。

## 确定材料及其用途

先区分当前稿件、审稿意见、风格样本和事实来源，记录用户指定的最新版本。

| 材料 | 本次用途 |
|---|---|
| 当前稿件 | 建立信息、论证、引用及结论力度的基线 |
| 风格样本 | 观察句式、用词、段落推进及章节功能 |
| 审稿意见 | 确认本次需要解决的表达问题 |
| 补充材料 | 补齐正文阅读或核查所需的上下文 |

样本数量按现有材料确定。有多篇时比较共同特点与文章之间的差异。样本缺失先阅读主稿；主稿缺失先分析已有样本并索取所需材料，不自行选取其他稿件代替。

## 完整阅读并记录覆盖

通读主稿及本次指定样本的全部可获得内容，包括标题、摘要、正文、图表、图注、参考文献表和已经提供的补充材料。长文连续分块阅读，不能用摘要、检索片段或被截断的工具输出代替全文。

扫描页、缺失表格或提取混乱的内容应补做视觉核对或文字识别。参考文献表中的每篇外部论文不自动纳入样本全文阅读范围。

记录每份材料的实际覆盖；尚未读到的部分保留明确状态。部分材料缺失时，先完成不依赖这些部分的工作，不声称已经通读。

| 材料代号 | 文件或题名 | 已读范围 | 缺失范围及影响 |
|---|---|---|---|
| 〈填写〉 | 〈填写〉 | 〈填写〉 | 〈填写〉 |

## 提炼可操作的风格特征

读完后再归纳特点，每项采纳的判断注明样本页码、章节或段落位置。将反复出现的习惯与期刊格式、单篇文章特有安排分开；单次出现不足以确定稳定风格。

| 维度 | 观察内容 |
|---|---|
| 问题进入 | 如何从具体问题或已有证据推进到研究目的 |
| 主语与动作 | 谁在观察、比较、解释或提出建议 |
| 措辞 | 动词、搭配及专业术语怎样承担信息 |
| 句子节奏 | 信息如何分配，长句与短句分别完成什么任务 |
| 段落推进 | 发现、依据、文献比较及解释如何衔接 |
| 引用方式 | 来源和主张怎样对应，何时需要点名研究者 |
| 条件与收束 | 必要限定如何连接主张，论点在哪里完成 |
| 章节功能 | 各节回答什么问题，怎样分配主要信息 |

用具体编辑决定表达分析结果，例如减少重复铺垫、明确观察主体或按原有论证拆分长句。不要只写“严谨、自然”，也不用统一句长或固定段式替代判断。

可使用[风格档案模板](style-profile-template.md)保存当次分析。本人历史档案仅作辅助，本次明确指定的样本与要求优先。跨语言参考时学习论证和节奏，使用目标语言自然的学术表达。

## 在内容基线上迁移表达

1. 按原段登记事实、数据、对象、比较、作者判断、未知事项、时间范围、限定及引文归属。
2. 调整搭配、主语、语序和句间衔接，逐项保留原稿信息。准确自然的句子可以保留，不以替换词数衡量改写程度。
3. 默认保持原章节及段落顺序。用户授权重排时，先说明安排，再核查论证关系、信息完整性、强调程度和引用支持范围。
4. 形成原创行文，不移植样本的独特句子、数据、论点、研究经历或参考文献。规范术语保持准确和一致。
5. 统一全文语体，再回查摘要、图表说明和结论中的独立主张。

## 处理机械段尾

逐段辨明末句承担的信息。无信息增量的防御套话直接精简；特定未知、负面事实及科学限制完整保留，并在等义条件下与对应主张自然整合。

不能仅把同一句移到句首或用分号连接就视为完成。段落在原有论点完成处结束，既不机械追加限制，也不补空泛积极总结。无法等义整合的限定保留原位。

## 全文核对与交付

- 对照内容基线，核查数字、分母、推断类型、否定范围及引用归属。
- 检查风格决定是否实际落实，尤其是讨论后半部分、摘要与结论。
- 按主入口完成交付检查；默认提供连贯修改稿，风格依据与阅读覆盖记录另列。
- 如实说明实际缺失材料；不保证检测分数、相似度或审稿结果。
